# {course}

## Course material

- `Canvas_docs/` is a copy of this course on Canvas, made by canvas_mirror.py. One folder per module, with every page, assignment and discussion as a `.md` file next to the files it links to. Google Docs and Slides are saved as PDF, Sheets as XLSX.
- The syllabus is in `Canvas_docs/Syllabus.md` (if the course has one), announcements are in `Canvas_docs/Announcements/`.
- `Canvas_docs/_overview.md` has all deadlines and the module structure. Start there to find things.
- Older versions of files that changed are in `Canvas_docs/_old/`.
- Don't edit anything in `Canvas_docs/`, the next run overwrites it. If something there looks outdated or wrong, tell the student.
- If `_MIRRORING_PROBLEM.md` exists in this folder, tell the student first: `Canvas_docs/` may be out of date.

## AI rules

- Find this course's rules on using AI in `Canvas_docs/` (often a page called "AI Usage", or part of the assessment info) and follow them. Summarize them below in a few lines, with the path to the source.
- If the course has no AI rules, act as a tutor: explain, review, quiz and point to the right material, but don't write graded work unless the student asks for it.

## Keeping context

- Keep this file up to date. When you learn something that will matter later (project details, team, decisions, teacher’s preferences or information that is "not in the slides"), add it here in the same turn. Short bullet points, facts only, no history. Remove what is no longer true.
- When a topic gets too big for this file (a project, an assignment, exam prep), move it to its own file in `context/` and link to it from here. Keep this file at most 200 lines long.
